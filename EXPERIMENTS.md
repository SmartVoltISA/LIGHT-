# EXPERIMENTS — Проверка LIGHT

## E0 — классический предел

Проверить, какие явления полностью описываются классической электродинамикой, а какие требуют квантового описания.

Критерий: заранее определить наблюдаемую величину и модельный предел.

## E1 — двойная щель

Проверить интерференцию при уменьшении интенсивности до режима регистрации отдельных фотонов.

Наблюдение: накопленная статистика сохраняет интерференционную структуру при подходящих условиях.

## E2 — фотоэффект

Связать частоту света с энергией электронов и проверить квантовое соотношение.

## E3 — поляризация

Проверить передачу и преобразование поляризационного состояния.

## E4 — спектральная передача

Измерить, как частота/спектр кодируют различимые состояния при прохождении через систему.

## E5 — light-by-light scattering

Высокоэнергетический тест QED: фотоны могут взаимодействовать косвенно через квантовые процессы. ATLAS сообщил прямое свидетельство такого рассеяния.

## Метод Ω-Stand

Для каждого нового эксперимента фиксировать:

`HYP-ID → гипотеза → H0 → метрика → параметры → тест → критерий → результат → воспроизводимость`.

Нельзя менять критерий успеха после получения результата.
