# LIGHT — СВЕТ — 光

Исследовательский репозиторий о природе света: от классической электродинамики до квантового поля, взаимодействия, информации и структурного анализа.

## Цель
Построить проверяемую карту света без подмены физики философской интерпретацией.

## Метод
1. **Факт** — установленная физика и эксперимент.
2. **Модель** — математическое описание фактов.
3. **Гипотеза** — наше предположение, требующее проверки.
4. **Тест** — наблюдение или вычисление, способное различить гипотезы.

## Базовая рабочая цепочка

`поле → возбуждение → распространение → взаимодействие → изменение состояния → измерение`

Это рабочая схема, а не утверждение о фундаментальной онтологии.

## Ветки

- `FIELD.md` — электромагнитное поле
- `PHOTON.md` — фотон и его состояния
- `PROPAGATION.md` — распространение, c и причинность
- `INTERACTION.md` — взаимодействие света и материи
- `INFORMATION.md` — различимые состояния и информация
- `GEOMETRY.md` — пространство-время и световой конус
- `Ω_MAPPING.md` — сопоставление с архитектурой Ω
- `EXPERIMENTS.md` — проверяемые тесты
- `QUESTIONS.md` — открытые вопросы
- `CHANGELOG.md` — история фиксаций

## Правило

Ни одна архитектурная интерпретация не считается физическим фактом без отдельного обоснования и проверяемого следствия.
