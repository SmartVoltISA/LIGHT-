# REL-65 — Boundary / global structure → observable content

## Question

Can global observable content be reconstructed from the existing relational,
historical and local-causal package, or does admissible global/boundary
structure have to enter as an additional physical assumption?

## Model

A finite ring-like system is represented by

`State = (local configuration, global label H)`.

The local observation reads only the local configuration. A closed-loop
operation reads the global label `H`.

Local evolution changes local configuration while retaining `H`.

## Controls

1. Two states have identical local configuration but different `H`.
2. Local observation therefore identifies them.
3. A closed-loop operation distinguishes them.
4. Local evolution preserves `H`, so the distinction survives as history /
   constraint.
5. The same distinction remains after identical local evolution.

## Result

**LOCAL OBSERVATIONS ALONE ↛ COMPLETE GLOBAL OBSERVABLE CONTENT.**

Conditional positive result:

`BOUNDARY / GLOBAL OPERATION ADMITTED`
→ `GLOBAL RELATIONAL STRUCTURE ACCESSIBLE`
→ `GLOBAL OBSERVABLE`

Thus global structure can become observable without becoming locally
observable.

## Interpretation for Ω

The experiment separates three claims:

`LOCALITY` restricts admissible local influence.

`HISTORY / MEMORY` can preserve a distinction that local dynamics does not
erase.

`GLOBAL / BOUNDARY ADMISSIBILITY` determines whether a retained global
relation can actually be probed.

Therefore the chain

`DISTINCTION → RELATION → STATE → TRANSITION → HISTORY → LOCALITY → BOUNDED INFLUENCE`

does not by itself determine the complete observable algebra.

A further admissibility question is required:

`BOUNDARY / GLOBAL OPERATIONS → ACCESSIBLE GLOBAL RELATIONS → OBSERVABLES`.

## Status

**CONDITIONAL POSITIVE + BOUNDARY**

Positive: when global/closed-loop operations are admitted, retained global
structure can be operationally distinguished.

Negative boundary: the admission of such operations and the relevant global /
boundary structure are not derived from local causality alone.

## Non-claims

This toy model does not derive gauge theory, Wilson loops, topology, boundary
charges, or any particular physical global observable. It only establishes the
logical countermodel: local causal admissibility is insufficient to exclude
physically distinguishable global sectors.
