# REL-45 — Maxwell action selection audit

## Question

After the previous chain reaches a compact/periodic Abelian U(1) structure, does the next minimal field-theory package select the Maxwell kinetic action rather than arbitrary alternatives?

## Conditional input package

The audit assumes, rather than derives:

1. 3+1-dimensional Lorentz covariance.
2. Local field theory.
3. U(1) gauge invariance.
4. A quadratic free-field action.
5. Parity-even kinetic sector.
6. At most two derivatives / renormalizable four-dimensional kinetic order.

These assumptions are deliberately exposed as inputs.

## Kernel argument

For a quadratic vector action in momentum space, write the most general Lorentz-covariant kernel at two-derivative order as

`K^{mu nu}(k) = a(k^2) eta^{mu nu} + b(k^2) k^mu k^nu`.

Gauge invariance requires the longitudinal direction to be null:

`K^{mu nu} k_nu = 0`.

Therefore

`a(k^2) + b(k^2) k^2 = 0`,

so the kernel is proportional to the transverse projector structure

`K ~ k^2 eta - k k`.

At two-derivative order this is exactly the quadratic structure generated by

`F_{mu nu} F^{mu nu}`.

Thus, **conditional on the stated package**, Maxwell's kinetic term is selected up to an overall normalization/coupling convention.

## Countermodels

### Proca

`L = -1/4 F^2 + 1/2 m^2 A^2`

The mass term is not U(1) gauge invariant. The numerical audit confirms that its quadratic kernel is not annihilated by the gauge direction.

### Higher derivative

`L = -1/4 F^2 + lambda F box F`

This remains gauge invariant, but introduces four derivatives and therefore lies outside the assumed two-derivative/renormalizable class.

### Topological term

`theta F_{mu nu} tilde(F)^{mu nu}`

For constant theta in ordinary 3+1-dimensional Abelian vacuum theory this is a total-derivative/topological contribution and does not change the local vacuum Maxwell equations. It therefore represents an allowed global/topological ambiguity rather than a new local propagating kinetic structure.

## Numerical audit

The accompanying Python script checks:

- Maxwell kernel: gauge residual < `1e-14`.
- Higher-derivative gauge-invariant deformation: residual < `1e-14`.
- Proca kernel: nonzero gauge residual.

The numerical test is a consistency check, not the proof of uniqueness; the uniqueness comes from the Lorentz-covariant tensor decomposition plus gauge-invariance constraint.

## Result

**CONDITIONAL POSITIVE.**

The package

`Lorentz covariance + locality + U(1) gauge invariance + quadraticity + parity-even + <=2 derivatives`

selects the Maxwell kinetic structure

`L_Maxwell = -1/4g^2 F_{mu nu} F^{mu nu}`

up to normalization/coupling and the possible constant theta topological term.

## What is NOT derived

This experiment does not derive:

- Lorentz covariance.
- spacetime metric/signature.
- 3+1 dimensions.
- compact U(1) itself.
- the action principle.
- the renormalizability criterion.
- the numerical electromagnetic coupling.
- SI units.
- hbar.

Therefore this is a **conditional selection result**, not a first-principles derivation of Maxwell electrodynamics from Ω.
